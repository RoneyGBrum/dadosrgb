Evolução da implementação da Lei nº 15.367/2026 — mês a mês. Desde a vigência (1º/abr/2026), o painel acompanha as duas correções previstas: o reposicionamento na classe (art. 310-B) e o posicionamento no salário (art. 310-A). Cada barra conta os servidores que tiveram alteração em relação ao mês anterior; a linha mostra o total acumulado no período.

Metodologia. Reposicionamento na classe = servidor cuja classe (A/B/C/D) mudou em relação ao mês anterior (colunas CLASSE_MAR…JUL_2026). Posicionamento no salário = servidor cuja remuneração variou em relação ao mês anterior (colunas Fev…Jul 2026). O grande volume de abr/2026 reflete a entrada em vigor da política em 1º/abr/2026. Um mesmo servidor pode ser corrigido em mais de um mês; por isso o total de correções é maior que o de servidores distintos.

Como adicionar linhas a este painel. Todos os dados estão embutidos na variável DATA no bloco <script> deste arquivo. Para acrescentar registros na seção "Dados Brutos", siga os passos abaixo.
Passo 1 — Copiar do Excel
  1. Abra Banco_de_Dados.xlsx no Excel ou Google Sheets.
  2. Selecione as linhas desejadas (mínimo as colunas listadas abaixo).
  3. Copie e cole em um editor de texto para extrair os valores separados.

Passo 4 — Onde inserir no HTML
  1. Abra este arquivo index.html em editor de texto (VS Code, Notepad++).
  2. Use Ctrl+F e busque por "sample_rows":[.
  3. Adicione novos objetos JSON separados por vírgula dentro do array.
  4. Salve e reabra no navegador — os registros aparecem automaticamente.
⚠️ Os KPIs, gráficos e totais são pré-calculados. Para atualizá-los com novos dados do Excel, é necessário rodar novamente o script Python gerador deste painel.
