Manual do Ecossistema de Movimentação de Pessoal

Do Data Lake ao painel publicado: o que o sistema faz, como rodar, o que cada número significa, que norma o sustenta e o que fazer quando algo dá errado.

Gerado em 06/09/2026 · competência de referência 2026-06 · 215.590 movimentações na base · 53.820 vigentes · CGMOP / SGP / MGI · uso interno
Capítulo 1

O que este ecossistema faz

Uma pergunta de política de pessoal, respondida com o dado que já existe.

O Governo federal movimenta servidores entre órgãos o tempo todo: cede, requisita, redistribui cargos, autoriza afastamentos. Cada um desses atos deixa rastro no SIAPE, mas o rastro é bruto — códigos, registros duplicados por matrícula, duas pontas do mesmo movimento em linhas diferentes. Responder “quantas pessoas o Ministério X cedeu e recebeu, e isso respeita a proporcionalidade do §7º do art. 93?” exigia dias de planilha.

Este ecossistema faz esse caminho todo dia, sozinho: lê o Data Lake, reconstrói cada movimentação, aplica as regras da norma e entrega nove painéis de página única que abrem no navegador, sem servidor e sem instalação para quem consulta.

O que é, e o que não é#

É
Um retrato do SIAPE numa competência, com as regras de negócio já aplicadas e as fontes declaradas em cada tela.
Não é
Um sistema transacional. Nada aqui altera o SIAPE — o fluxo é de leitura, só.
É
Uma ferramenta de acompanhamento: indica onde olhar, quantifica, compara com a norma.
Não é
A apuração oficial de nenhum indicador. Quando um decreto manda o MGI divulgar um número, o número oficial é o do MGI; aqui é acompanhamento com fonte declarada.

Como as peças se encaixam#

A regra de ouro deste projeto

Todo número na tela tem de dizer de onde veio e de quando é. Por isso cada painel carrega a competência de referência no cabeçalho, e cada afirmação de conformidade é amarrada a essa competência — “na competência 06/2026, atende”, nunca “atende”.

Por que os painéis são HTML de arquivo único#

Cada painel embute os próprios dados e o próprio JavaScript. Não há servidor, banco, API nem build. As consequências práticas:

  • Quem consulta só precisa de um navegador — abre até de um pen drive.
  • Publicar é copiar arquivo. Não há infraestrutura para cair às 23h de uma sexta.
  • Em compensação, os arquivos são grandes (o painel de Pessoal passa de 35 MB) e todo o dado embutido é legível por quem tiver o arquivo — ver o capítulo de privacidade.

Capítulo 4

Pré-requisitos e instalação

O que precisa existir na máquina antes do primeiro comando.

  1. Python 3.11 ou mais novo

    Confira com python --version. O projeto roda no Anaconda ou no Python oficial — tanto faz, desde que seja o mesmo interpretador em todos os passos.

  2. Acesso ao Data Lake

    Credenciais do Databricks do MGI. Sem elas dá para gerar painéis a partir de uma extração que já esteja em PASTA_DADOS, mas não para atualizar a base.

  3. A pasta de dados

    Um lugar fora do projeto para os dados sensíveis — tipicamente a pasta da equipe no OneDrive. Ver o capítulo seguinte.

  4. As bibliotecas

    O assistente instala tudo sozinho. Manualmente: pip install -r requirements.txt.

Ambiente virtual (opcional, recomendado)#

O assistente cria e usa um ambiente virtual se você quiser, pela aba Ambiente. Na mão:

PowerShell
cd C:\0_Desenvolvimento\Movimentacao_pessoal\pipeline
python -m venv C:\projetos_ia\venv_ia
C:\projetos_ia\venv_ia\Scripts\activate
pip install -r requirements.txt
Se você não sabe se precisa de venv

Não precisa. O ambiente virtual serve para isolar versões de biblioteca quando a mesma máquina roda vários projetos. Se esta máquina só roda este, o Python do sistema basta.

Trocar a PASTA_DADOS tem efeito colateral

Já aconteceu: ao mudar a pasta, o cache de vagas por órgão ficou para trás e o painel passou a mostrar vagas em branco sem avisar. Hoje esse cache é gravado também em pipeline/reference/ (é dado público) e a falta dele vira erro destacado no log. Ainda assim, depois de mudar a pasta, rode a conferência de chaves.

O arquivo de referência da competência#

output/referencia.json guarda a competência do último processamento. É a guarda contra um problema real que já ocorreu: o fatoServidor voltar uma competência antiga sem ninguém notar. Se a competência recuar, o painel avisa a defasagem em vez de exibir número velho como se fosse novo.

Por que o limite de reembolso é procurado em dois lugares#

O limites_reembolso.csv é lido primeiro da PASTA_DADOS e só depois de reference/. Assim a equipe cadastra a portaria nova junto com os dados, sem precisar mexer no repositório; a cópia versionada fica como semente e rede de segurança. O log diz sempre qual dos dois foi usado.

Um defeito real que essa tabela já teve

Em 04/09/2026 o exercício 2026 apareceu com 47 links diferentes para a mesma portaria, com o número final incrementando (…601, …602, …). É a marca do arrastar-célula do Excel: ao puxar a fórmula para baixo, ele incrementou o id da URL. Um ato do DOU tem um id — 46 daqueles endereços não existiam. Hoje o gerador avisa quando um exercício tem mais de um valor distinto em portaria ou link.

Ao editar no Excel, cuidado com três coisas
  • Arrastar célula incrementa números dentro de texto, inclusive dentro de URLs.
  • Ponto e vírgula dentro de um campo desloca todas as colunas da linha (já aconteceu no reembolso_cct.csv).
  • Salvar como CSV mantendo o separador ; e a codificação UTF-8.
Capítulo 10

O pipeline, etapa por etapa

O que acontece entre o comando e o CSV.

Etapa 1 — Extração#

Consulta o Data Lake e grava parquet cru em raw/: o fato_servidor (o retrato de cada vínculo), as dimensões (órgão, situação, cargo, cor/raça, escolaridade, unidade organizacional…) e a ficha financeira da competência mais recente disponível.

As consultas trazem colunas por SELECT *

É proposital. Se o Data Lake deixar de entregar uma coluna, o campo correspondente fica vazio com um aviso no log em vez de a rodada inteira quebrar. Em compensação, é preciso ler o log: uma coluna que sumiu em silêncio vira um painel com um filtro morto.

Etapa 2 — Montagem das movimentações#

É a etapa com mais regra de negócio, porque o SIAPE não tem uma tabela de movimentações. Cada movimento deixa duas marcas, em registros diferentes: a saída no órgão de origem e a entrada no de destino. O pipeline casa as duas por CPF e data.

  • Deduplicação por matrícula: o mesmo servidor tem um registro por vínculo. Sem tratar, cada matrícula geraria uma linha do mesmo movimento. Mantém-se um por (CPF, origem, destino, data de ingresso), priorizando o ativo.
  • Origem == destino sai fora: não é movimentação entre órgãos, é resíduo de reforma administrativa (o órgão trocou de código, não a pessoa de casa).
  • GDF e DPU: movimentos internos ao Governo do DF saem; quem tem só uma ponta no GDF fica.
  • Colapso de reforma: quando o órgão se transformou (MP → ME → MGI), a trilha vira uma cadeia de siglas em vez de várias movimentações falsas.

Etapa 3 — Dimensões e taxonomias#

Códigos viram nomes legíveis, e entram as classificações da equipe: setor e poder do órgão, natureza estatal pelas listas da SEST, conceitos das situações funcionais.

Etapa 4 — Enriquecimento#

Demografia, tempo de movimentação, remuneração da ficha financeira, nível de liderança e vagas por órgão. É aqui que se aplica a taxonomia de funções.

Etapa 5 — Exportação#

ArquivoO que é
movimentacoes_painel.csvA base — uma linha por movimentação, 70 colunas.
saldo_orgaos.csvPlacar por órgão: cede, recebe, saldo, vagas aprovadas e ocupadas.

Capítulo 11

Conceitos que mudam o número

As definições que, se lidas errado, levam à conclusão errada.

Vigente ≠ ativo#

Vigente é o vínculo que ainda existe no SIAPE — inclui aposentados e pensionistas. Ativo é o vínculo em situação funcional ativa. A diferença é grande: dos 1,12 milhão de vínculos vigentes, cerca de 656 mil são ativos e 409 mil são aposentados. Usar um no lugar do outro erra por 40%.

Servidores ativos ≠ força de trabalho#

Servidor ativo é a situação do vínculo, e inclui quem está cedido para outro órgão. Força de trabalho conta só quem está em exercício no próprio órgão. O KPI de força de trabalho saiu da faixa principal do painel de Pessoal justamente porque, lado a lado com “servidores ativos”, confundia mais do que informava — mas segue como gráfico e como filtro.

Pessoas ≠ vínculos#

Um servidor pode ter matrícula em mais de um órgão. Contagens de pessoas deduplicam por CPF; gráficos por órgão contam vínculos, porque a pessoa aparece em cada órgão onde tem matrícula. São 1,12 milhão de vínculos para ~1,08 milhão de pessoas.

Origem e destino moram em linhas diferentes#

A situação funcional da origem e a do destino vêm de registros distintos do SIAPE. O pipeline preenche as duas pontas: movimento só-origem recebe no destino a mesma situação que descreve a cessão; movimento só-destino recebe na origem a situação-base do servidor. Nenhum preenchimento sobrescreve o que veio da própria ponta.

O passado não alimenta o presente#

O caso INFRAERO

Uma servidora originária da INFRAERO aparecia com cargo no painel. Investigando: o cargo vinha de uma matrícula excluída dela. O pipeline pegava o registro mais recente com valor, sem olhar se aquele vínculo ainda existia.

Hoje há duas listas: atributos do vínculo atual (cargo, função, nível da função, PGD, lotação, UPAG, município) só são herdados de matrícula vigente; atributos estáveis (nome, nascimento, sexo, cor) ainda podem vir de matrícula excluída — senão quem só tem vínculo encerrado ficaria sem nome no painel.

Competência de referência#

Todo painel é um retrato de uma competência, indicada no cabeçalho. Conclusões de conformidade são sempre amarradas a ela: “na competência 06/2026, os dois grupos atendem o mínimo”. Outra competência pode dar outro resultado, e a frase precisa deixar isso evidente.

Proporcionalidade do §7º do art. 93#

A ideia da norma: o órgão que recebe pessoas para compor sua força de trabalho deve, na mesma medida, liberar. O painel calcula por órgão o que cede (A), o que recebe (B) e o saldo (C = A − B), cruzando com vagas aprovadas (D) e ocupadas (E). Cada coluna derivada vem explicada na tela e no PDF — C/E, % Ocup./Aprov., % Lib. A/E, % Oriundos B/E e % Mov. Força de Trabalho.

Capítulo 12

Os painéis, um a um

O que cada tela responde, e o que ela não responde.

Todos compartilham a mesma gramática: filtros no topo, filtros aplicados no trilho lateral, gráficos clicáveis com multi-seleção, exportação em PDF e planilha.

A regra da multi-seleção

Sempre que se filtra clicando num gráfico, é possível escolher mais de uma barra. O gráfico de uma dimensão aplica todos os filtros menos o dela mesma — por isso todas as barras continuam à vista e cada clique acrescenta, em vez de trocar.

Movimentações#

O painel central. Vigentes e histórico, quem cede e quem recebe, tipos de movimentação, setor e natureza estatal das duas pontas, tempo médio no destino, encerramentos e motivos de saída. Tem a relação nominal, com ficha individual, trajetória do servidor (todas as movimentações da mesma pessoa) e a aba de Proporcionalidade.

  • Recortes: vigentes ou histórico completo, com período ajustável.
  • Relatórios: executivo geral, ficha individual, trajetória e o de proporcionalidade — este último com a tabela larga, mas impresso em papel em pé.
  • Versão pública: arquivo separado, sem a aba de proporcionalidade e sem os campos que não devem circular.

Pessoal#

Quadro agregado do Executivo federal — sem nome, CPF ou matrícula. É um cubo de ~560 mil combinações que responde a qualquer cruzamento das 16 dimensões.

  • Órgão de lotação e órgão de exercício são coisas diferentes: 96% coincidem, e os 4% restantes são quem está cedido ou requisitado.
  • UF de exercício vem do município de exercício (código IBGE), com 99,6% de cobertura, e aparece como mapa de blocos. A antiga “UF da UPAG” saiu: a UPAG é unidade pagadora, não diz onde a pessoa trabalha.
  • Natureza jurídica é a do órgão de lotação — está dito no rótulo.
  • Fora do grupo “Composição do quadro”, cada barra, coluna ou fatia mostra também a remuneração média daquele grupo.
  • Dois cartões de liderança: mulheres e homens por nível, e o acompanhamento do Decreto 11.443/2023. Cada um declara o próprio universo, porque contam populações diferentes — ver o capítulo da norma.

Anistiados#

Ficha funcional do público da Lei 8.878/94: de onde vieram, por onde passaram, onde estão hoje, remuneração e tempo de retorno. A situação atual está em três botões com o respectivo quantitativo, acima da primeira linha de filtros.

Piso de anonimato

Os gráficos de sexo, cor/raça e escolaridade reagem aos filtros, mas somem quando o recorte tem menos de 10 pessoas — abaixo disso, o gráfico apontaria o atributo de indivíduos. No lugar aparece o aviso, dizendo quantos sobraram.

Redistribuição#

Cargos redistribuídos entre órgãos (art. 37 da Lei 8.112/90): de onde para onde, saldo por órgão, série histórica, perfis e a matriz origem × destino — 12 maiores origens nas linhas contra 12 maiores destinos nas colunas, com a célula colorida pela intensidade e clicável para filtrar o par.

Origem “não informada”

O destino é sempre conhecido; a origem é reconstruída casando saída e entrada por CPF e data. Quando esse par não existe, a origem fica “não informada” — a redistribuição continua contada no total, mas não entra nos gráficos de quem cedeu nem na matriz. O “i” ao lado da matriz traz o percentual do recorte.

LIP — Interesse Particular#

Licenças do art. 91 desde 2011: órgão, cargo, carreira, duração e situação de cada afastamento, com a lista nominal.

Radar do Exterior e Quinquênio#

Dois painéis de conformidade, não de contagem. O Radar cruza quem está fora do País (art. 96) com a folha e com a fila do que a lei manda conferir. O Quinquênio acompanha o teto de 90 dias por quinquênio (art. 87) e a carência de 2 anos antes da pós (art. 96-A).

Códigos de afastamento mudam quando a norma muda

A licença capacitação migrou de código com o Decreto 9.991/2019 — o código legado morre em 03/2023. Se um painel de afastamento mostrar uma série que cai a zero numa data redonda, desconfie de troca de código antes de desconfiar do dado.

Limites de Reembolso#

Junta duas metades da mesma história: quanto cada órgão já gastou do teto da portaria conjunta MGI/MPO (execução do SIOP) e quem são os empregados de estatal cedidos por trás dessa despesa (SIAPE).

  • Termômetro do teto: liquidado, empenhado a liquidar e saldo na escala do teto, com a marca de onde o calendário está — vê-se num golpe se o gasto está adiantado ou atrasado.
  • IHE (Índice Histórico de Execução): média do percentual do teto usado por ano, com o ano em curso proporcional aos dias decorridos.
  • Simulação de custo com parâmetros editáveis e um campo para projetar entradas além do efetivo — a projeção entra no total e fica registrada no relatório.
  • Simulação de reajuste de convenção coletiva, com as duas bases explicadas.
Capítulo 13

Liderança e o Decreto 11.443/2023

Onde a classificação da casa encontra a norma — e onde elas divergem.

A taxonomia de liderança é nossa, não da norma#

A separação Alta × Baixa/Média vem da planilha FUNÇÕES.xlsx, mantida pela CGMOP. Onde a função tem equivalência ao DAS, a planilha conta DAS 4, 5, 6 e Natureza Especial como alta liderança, e DAS 1, 2 e 3 como baixa/média.

Onde fica a fronteira é escolha, não norma

Os estudos que analisam os dados do Observatório de Pessoal costumam usar um corte mais estreito: alta liderança só o equivalente a DAS 5 e 6. A diferença não é pequena — cerca de 63% do que o painel chama de alta liderança tem equivalência a DAS 4. Pelo outro corte o grupo cairia de ~21,7 mil para ~8,1 mil funções, e a proporção de mulheres nele iria de 38,6% para 36,9%. A conclusão não muda; o tamanho do grupo muda quase três vezes. Para adotar outro corte, basta editar a coluna de nível na planilha e gerar de novo.

O Decreto nº 11.443/2023#

O que a norma manda

Art. 3º — os órgãos devem preencher com pessoas negras, no mínimo, 30% dos CCE e FCE de níveis 1 a 12 (inciso I) e 30% dos de níveis 13 a 17 (inciso II).
§1º — prazo até 31/12/2025.
Art. 4º — a apuração é global por grupo de níveis, não órgão a órgão.
Art. 2º e 6º — pessoas negras são as autodeclaradas pretas e pardas, com registro no Sinc.
§4º — há também um mínimo de mulheres, a ser definido em ato conjunto MIR/MGI.
Art. 1º, par. único — não se aplica a cargos privativos de militares nem quando lei específica trate da escolha do ocupante.

Como o painel afere — e o que ele não alcança#

Entram os vínculos vigentes do SIAPE nas famílias FEX e CCX, com o nível nos dois últimos dígitos do código. A cor/raça está preenchida em 100% desses vínculos, e o denominador inclui os nomeados sem vínculo anterior.

Os limites do indicador

Não é a apuração oficial — essa cabe ao MGI divulgar (art. 9º). Não há como separar as exceções do art. 1º; a autodeclaração oficial fica no Sinc e aqui usa-se a cor do SIAPE; o resultado da comissão de heteroidentificação (art. 7º) não chega a esta base; e o painel exclui GDF/PMDF/CBMDF/PCDF e DPU. O mínimo de mulheres do §4º depende de ato conjunto ainda não editado — sem ele, não há parâmetro a conferir.

Dois cartões, dois universos#

O cartão de gênero conta todas as famílias de função (≈265,6 mil vínculos). O do decreto conta só CCE e FCE (≈53,3 mil) — cinco vezes menos, e um subconjunto do primeiro. Cada cartão declara o próprio universo na tela, porque comparar os percentuais como se fossem a mesma base leva à conclusão errada.

Uma coincidência que não é coincidência

O grupo II do decreto (níveis 13 a 17) tem exatamente o mesmo total da “alta liderança” dentro do CCE/FCE. É consequência da régua da casa: DAS 4 ≡ nível 13. Ou seja, dentro do CCE/FCE os dois cortes são o mesmo conjunto; a diferença de tamanho vem das outras famílias.

O que circula, com que proteção, e o que essa proteção não faz.

O que fica embutido em cada painel#

Painéis de arquivo único carregam o dado dentro do HTML. Esconder na interface não é o mesmo que não publicar: quem tem o arquivo pode ler o código-fonte. As decisões atuais:

O portão de acesso#

O login é atrito, não segurança

Os painéis publicados recebem uma tela de usuário e senha, com a senha verificada por PBKDF2-HMAC-SHA256 (250 mil iterações) no próprio navegador. Isso não é controle de acesso: o servidor entrega o arquivo inteiro a quem pedir a URL, e o conteúdo está dentro dele. Serve para evitar acesso casual, não determinado.

Acesso real exigiria autenticação no servidor — Azure Static Web Apps com Entra ID, ou Cloudflare Access. Enquanto isso não existe, trate a URL como o segredo.

O que fica no ar#

A aba O que fica no ar do assistente decide painel a painel. “Em revisão” mantém o cartão no hub, sem link, e remove o arquivo da pasta publicada — o link volta 404. Serve para anunciar que o estudo existe enquanto os números são conferidos.

Capítulo 16

As planilhas internas

O material de trabalho: tudo, com nome e CPF, fora da web.

Os painéis mascaram e agregam. Internamente às vezes é preciso o dado completo — por pessoa, com nome, CPF e matrícula. A cada rodada o pipeline grava um arquivo por base em PASTA_DADOS/planilhas_internas/, com a data no nome.

Estas planilhas NUNCA vão para a web

Elas ficam na pasta da equipe e só. Nenhuma etapa de publicação as toca: publicar_cgmop.py copia apenas os HTML dos painéis e o manual. Tratar esses arquivos como qualquer outro anexo de e-mail é o jeito mais fácil de transformar um painel cuidadoso num incidente de privacidade.

Três decisões que valem conhecer#

Pessoal vem separado
Ativos, aposentados e demais em arquivos distintos. Não é capricho: 1,12 milhão de vínculos não cabe numa aba do Excel, que aceita 1.048.576 linhas.
Base grande sai em streaming
Acima de 250 mil linhas o arquivo é escrito sem manter as células na memória (a primeira tentativa consumiu 5 GB e não terminou) e vem com um CSV ao lado, que é o que serve para carregar o volume inteiro de uma vez. Nesse modo não há gráficos.
GDF e DPU entram
Os painéis excluem o Governo do DF (e forças) e a DPU; as planilhas internas trazem o quadro completo. Nas bases de movimentação o que os painéis tiram é só o que tem as duas pontas nesse conjunto — quem tem uma ponta federal sempre esteve lá.

O CPF completo#

O movimentacoes_painel.csv guarda CPF mascarado, de propósito: é ele que alimenta os painéis publicados. O CPF inteiro vai para uma tabela pequena em output/interno/movimentacoes_cpf.csv, gravada pelo pipeline, e a planilha interna junta as duas na hora de montar o arquivo.

Por que não refazer a associação depois

Seria tentador casar CPF e movimento por matrícula no próprio exportador. Não: esse casamento já trocou a pessoa de lugar uma vez — 234 linhas exibiam remuneração e afastamento de outra pessoa. A associação sai do pipeline porque é lá que ela é construída e conferida contra o CPF.

Como gerar sem rodar tudo

Pela aba Pipeline do assistente, marcando só “Planilhas internas”. Na mão: python -m src.exportar_planilhas_internas, de dentro de pipeline/. A pasta abre pela aba Tabelas.

Checklist antes de publicar#

  1. A competência é a esperada?

    Confira no cabeçalho de qualquer painel.

  2. O log tem WARNING?

    Coluna ausente e taxonomia incompleta aparecem lá.

  3. Rodou as duas conferências?

    Chaves do reembolso e taxonomias, na aba Tabelas.

    Cede e recebe têm de bater; o teto do reembolso tem de bater com a soma dos anexos da portaria.

    São os dois caminhos que mais quebram em silêncio.

  6. Conferiu o arquivo publicado?

    Não só o gerado — a publicação altera a página.

Capítulo 17

Solução de problemas

Sintoma, causa provável, o que fazer.

O painel abre com o JavaScript aparecendo como texto#

Acontece só no arquivo publicado. Causa: a injeção do portão de login entrou no meio de um bloco de script. Verifique se algum texto do gerador contém um </body> ou <script> literal dentro de uma string JavaScript.

O relatório em PDF sai em branco, ou com folhas vazias no fim#

Regra de impressão. O conteúdo tem de estar em #pdf-doc, que precisa ser filho direto do <body>, e os irmãos dele têm de sair com display:none — visibility:hidden esconde mas mantém o espaço, e é isso que produz dezenas de folhas em branco.

Como testar impressão sem imprimir

Aplique na tela as regras do @media print e meça: document.body.scrollHeight − #pdf-doc.scrollHeight tem de dar zero. Se der mais que zero, é exatamente esse tanto de papel em branco.

A planilha não abre, ou o Excel pede para reparar#

Foi um defeito real e antigo: o gerador de XLSX escrevia o diretório central do ZIP com 44 bytes em vez de 46 (faltavam os dois bytes de “atributos internos”), e toda planilha do ecossistema saía corrompida. Corrigido. Se voltar a acontecer, valide abrindo o arquivo com openpyxl — baixar sem erro não prova nada.

Só consigo selecionar uma barra do gráfico#

O gráfico de uma dimensão está aplicando o filtro dela mesma — aí sobra uma barra só e não há o que clicar. Ele precisa aplicar todos os filtros menos o próprio.

Um órgão aparece com execução zero sem explicação#

Falta de-para entre SIAPE e SIOP. Rode Conferir chaves do reembolso: ele aponta a linha exata que falta, com o volume de dinheiro e de gente em jogo.

“Função fora da taxonomia” com volume alto#

Famílias de função que não estão na FUNÇÕES.xlsx. Rode Conferir taxonomias; com --csv ele grava a lista pronta para preencher.

O painel some do ar (404)#

Provavelmente está marcado como em revisão na aba “O que fica no ar” — nesse estado o arquivo é removido da pasta publicada de propósito.
